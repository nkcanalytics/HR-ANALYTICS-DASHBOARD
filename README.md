# HR Analytics Dashboard | Power BI

## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It helps analyze employee-related information, salary distribution, departmental workforce, gender distribution, and education-based salary patterns.

The dashboard presents key Human Resources (HR) metrics in a clear and interactive format, helping users explore workforce data and understand important HR indicators.

## 🎯 Project Objectives

- Analyze the total number of employees in the organization.
- Monitor total salaries and average salary.
- Understand employee distribution across departments.
- Compare average salaries across different departments.
- Analyze workforce distribution by gender.
- Explore average salary patterns based on education.
- Enable interactive analysis using slicers and filters.
- Present HR information through an easy-to-understand dashboard.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **HR Employee Dataset** – Employee-related information used for analysis.
- **Power BI Measures** – Calculation and presentation of key HR metrics.
- **Data Visualization** – Charts, KPI cards, and interactive filters.

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

1. **Total Salaries** – Displays the total salary value represented by the dashboard's measure.
2. **Total Employee Count** – Shows the number of employees.
3. **Average Age** – Presents the average age of employees.
4. **Average Salary** – Displays the average salary of employees.

## 📈 Dashboard Features

### 1. Employee Count by Department
A column chart that compares employee counts across departments and helps explore workforce distribution.

### 2. Average Salary by Department
A column chart that compares average salaries across departments.

### 3. Employee Distribution by Gender
A donut chart that visualizes the employee count by gender.

### 4. Average Salary by Education
A column chart that compares average salary across education categories.

### 5. Gender-Based Salary Analysis
A pie chart configured to display average salary by gender, allowing salary patterns to be explored. A bar chart can also be used for a clearer comparison.

### 6. Interactive Slicers
The dashboard provides four slicers:
- Department
- Job Role
- Gender
- Education

These filters allow users to explore the dashboard according to selected employee categories.

## 💡 Business Value

This dashboard demonstrates how HR data can be transformed into meaningful visual information. It can support HR teams and management in:

- Understanding workforce distribution.
- Reviewing salary patterns across departments.
- Exploring gender-based workforce information.
- Comparing employee salary metrics across education categories.
- Making data-informed decisions about workforce planning and HR reporting.

Actual business conclusions should be drawn after reviewing the underlying data and validated KPI values.
